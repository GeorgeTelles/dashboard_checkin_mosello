## 1. Seu Papel no Sistema

### 👨‍💼 Quem é o Supervisor de Pauta?

Você é o **responsável pela pauta** da sua área (Controle Trabalhista, Controle Cível, etc.) e tem um papel fundamental no Sistema de Check-in de Audiências.

### 📋 Suas Responsabilidades

Como supervisor de pauta, você é responsável por:

- **Monitorar** o comparecimento dos advogados às audiências
- **Agir rapidamente** quando um advogado não faz check-in ou check-out
- **Garantir** que todas as audiências sejam acompanhadas adequadamente
- **Manter** o cadastro de telefones dos advogados atualizado
- **Escalar** situações críticas para a gestão quando necessário

### ✨ Por que seu papel é importante?

O sistema automatiza o acompanhamento das audiências, mas **você é a última linha de defesa**. Quando um advogado não responde, você recebe um alerta para tomar ação imediata e evitar problemas como:

- Audiências perdidas
- Falta de acompanhamento de processos importantes
- Desorganização da pauta do escritório

## 2. Quando Você Receberá Mensagens

Você receberá mensagens de alerta em **3 cenários específicos**:

### 📲 Cenário 1: Advogado Sem Telefone Cadastrado

**Quando acontece:** Logo que o sistema detecta uma audiência de um advogado que não tem telefone cadastrado no sistema.

**Por que você recebe:** O sistema não consegue enviar a mensagem de check-in para o advogado, então envia diretamente para você.

**Timing:** Quando o sistema tenta enviar a mensagem de check-in (30 minutos antes da audiência).

---

### 📲 Cenário 2: Check-in Não Realizado

**Quando acontece:** O advogado recebeu a mensagem de check-in mas não respondeu.

**Por que você recebe:** Para que você possa entrar em contato com o advogado e confirmar se ele vai comparecer à audiência.

**Timing:** **15 minutos antes** do horário da audiência.


**Exemplo de linha do tempo:**
- 08:10 - Sistema envia mensagem de check-in ao advogado
- 08:25 - Advogado não respondeu → **Você recebe alerta** (15 min antes)
- 08:40 - Horário da audiência

---

### 📲 Cenário 3: Check-out Não Realizado

**Quando acontece:** O advogado recebeu a mensagem de check-out mas não respondeu.

**Por que você recebe:** Para que você possa verificar se a audiência ocorreu e se está tudo bem com o advogado.

**Timing:** **45 minutos após** o horário da audiência.

**Exemplo de linha do tempo:**
- 08:40 - Horário da audiência
- 08:41 - Sistema envia mensagem de check-out ao advogado
- 09:25 - Advogado não respondeu → **Você recebe alerta** (45 min após)

## 3. O que Fazer em Cada Cenário

### 🔧 Cenário 1: Advogado Sem Telefone Cadastrado

#### ✅ Procedimento Recomendado

1. **Identifique o advogado** na mensagem de alerta
2. **Entre em contato** com o advogado imediatamente
   - Use telefone do escritório
   - Use e-mail corporativo
   - Use outros canais de comunicação disponíveis
3. **Confirme a presença** do advogado na audiência
4. **Solicite o número de telefone** do advogado para cadastro
5. **Atualize o cadastro** no sistema (veja seção 4)
6. **Monitore** se o advogado compareceu à audiência

#### ⚠️ Atenção

- Este cenário é **urgente** pois você recebe o alerta apenas 30 minutos antes da audiência
- Priorize o contato imediato com o advogado
- Se não conseguir contato, escale para a gestão imediatamente

---

### 🔧 Cenário 2: Check-in Não Realizado (15 min antes)

#### ✅ Procedimento Recomendado

1. **Leia a mensagem de alerta** com atenção
2. **Ligue para o advogado** imediatamente
   - Use o telefone cadastrado no sistema
   - Se não atender, tente outros números conhecidos
3. **Confirme se o advogado vai comparecer**
   - Se SIM: Oriente o advogado a responder a mensagem
   - Se NÃO: Tome as providências necessárias (reagendar, informar cliente, etc.)
4. **Registre a situação** internamente
5. **Monitore** se o advogado compareceu

#### ⚠️ Atenção

- Você tem apenas **15 minutos** para agir antes da audiência
- Priorize o contato telefônico (mais rápido que WhatsApp)
- Se não conseguir contato em 5 minutos, escale para a gestão

---

### 🔧 Cenário 3: Check-out Não Realizado (45 min após)

#### ✅ Procedimento Recomendado

1. **Leia a mensagem de alerta** com atenção
2. **Verifique se a audiência estava confirmada**
   - Consulte o sistema DataJuri
   - Verifique se houve cancelamento de última hora
3. **Entre em contato com o advogado**
   - Ligue ou envie mensagem no WhatsApp
   - Pergunte se a audiência ocorreu
   - Pergunte se está tudo bem
4. **Registre o resultado**
   - Se audiência ocorreu: Oriente o advogado a responder a mensagem
   - Se audiência não ocorreu: Registre o motivo
   - Se houve problema: Escale para a gestão

#### ⚠️ Atenção

- Este cenário é **menos urgente** (audiência já passou)
- Foco é verificar se está tudo bem e atualizar registros
- Pode ser que o advogado esteja ocupado - tente contato algumas vezes

## 4. Como Verificar Status das Audiências

### 📊 Onde Consultar Informações

Você pode verificar o status das audiências em dois lugares:

#### 1. Sistema DataJuri (Banco de Origem)

- Acesse o sistema DataJuri normalmente
- Consulte a agenda do dia
- Verifique informações da audiência (horário, local, status)

#### 2. Banco de Controle (audiencias_check)

- Acesse o banco de dados PostgreSQL
- Consulte a tabela `audiencias_check`
- Veja status detalhado de check-in e check-out

### 📋 Como Interpretar os Status

#### Status de Check-in (status_checkin)

| Status | Significado | O que fazer |
|--------|-------------|-------------|
| `null` | Mensagem ainda não foi enviada | Aguardar - sistema enviará em breve |
| `a confirmar` | Mensagem enviada, aguardando resposta | Monitorar - se não responder, você receberá alerta |
| `confirmado` | Advogado confirmou presença (respondeu "1") | Tudo certo! ✅ |
| `não vai comparecer` | Advogado informou que não vai (respondeu "2") | Tomar providências necessárias |
| `não realizado` | Advogado não respondeu e horário passou | Verificar o que aconteceu |

#### Status de Check-out (status_checkout)

| Status | Significado | O que fazer |
|--------|-------------|-------------|
| `null` | Mensagem ainda não foi enviada | Aguardar - sistema enviará após audiência |
| `a confirmar` | Mensagem enviada, aguardando resposta | Monitorar - se não responder, você receberá alerta |
| `confirmado` | Advogado confirmou participação (respondeu "1") | Tudo certo! ✅ |
| `não participou` | Advogado informou que não participou (respondeu "2") | Verificar motivo |
| `não realizado` | Advogado não respondeu | Entrar em contato para verificar |

### 🔍 Consulta SQL Útil

Se você tem acesso ao banco de dados, pode usar esta consulta para ver todas as audiências do dia:

```sql
SELECT 
  id,
  "encarregado.nome" as advogado,
  "processo.pasta" as processo,
  hora,
  status_checkin,
  status_checkout,
  encontrado_na_lista
FROM audiencias_check
WHERE data = TO_CHAR(CURRENT_DATE, 'DD/MM/YYYY')
ORDER BY hora;
```

## 5. Como Entrar em Contato com o Advogado

### 📞 Telefones de Contato

#### Opção 1: Telefone Cadastrado no Sistema

O telefone do advogado está disponível na mensagem de alerta que você recebe. Você também pode consultar:

- Sistema DataJuri (cadastro de usuários)
- Planilha interna de contatos
- Banco de dados (campo `telefone` na tabela `audiencias_check`)

#### Opção 2: Telefone do Escritório

Se o telefone cadastrado não funcionar, tente:

- Ramal do advogado no escritório
- Telefone da secretária/assistente do advogado
- Telefone de outros advogados da mesma área

### 📱 Procedimento Recomendado de Contato

#### Para Cenários Urgentes (1 e 2)

1. **Ligue imediatamente** para o telefone cadastrado
2. Se não atender em 2 toques, **tente outro número**
3. Se não conseguir contato telefônico, **envie WhatsApp**
4. Se não responder em 3 minutos, **escale para gestão**

#### Para Cenário 3 (menos urgente)

1. **Envie mensagem no WhatsApp** primeiro
2. Se não responder em 10 minutos, **ligue**
3. Se não conseguir contato, **tente novamente em 30 minutos**
4. Se ainda não conseguir, **registre e informe gestão**

### 💬 Modelo de Mensagem

**Para Check-in não realizado:**
```
Olá [Nome], tudo bem? 

Vi que você tem audiência às [hora] e ainda não fez o check-in no sistema. 

Você vai comparecer? Por favor, responda a mensagem do sistema para confirmar.

Qualquer dúvida, estou à disposição!
```

**Para Check-out não realizado:**
```
Olá [Nome], tudo bem?

Vi que você tinha audiência às [hora] hoje. A audiência ocorreu normalmente?

Por favor, responda a mensagem do sistema para confirmar.

Obrigado!
```

## 8. Perguntas Frequentes (FAQ)

### ❓ E se eu não conseguir contato com o advogado?

**Resposta:** Depende do cenário:

**Cenários 1 e 2 (urgentes):**
- Tente todos os canais disponíveis (telefone, WhatsApp, e-mail, ramal)
- Se não conseguir contato em **5 minutos**, escale imediatamente para a gestão
- A gestão pode tomar decisões como: enviar outro advogado, reagendar, etc.

**Cenário 3 (menos urgente):**
- Tente contato algumas vezes ao longo de 1-2 horas
- Se não conseguir, registre a ocorrência e informe a gestão
- Monitore se o advogado responde posteriormente

### ❓ E se a audiência foi cancelada?

**Resposta:** 

1. **Verifique no sistema DataJuri** se o cancelamento está registrado
2. Se foi cancelada mas o sistema enviou mensagem:
   - É normal - o cancelamento pode ter sido de última hora
   - Não precisa tomar ação urgente
3. **Registre a situação** internamente para referência futura
4. Se o advogado responder, oriente a responder "2" (não vai comparecer/não participou)

### ❓ Como atualizar o cadastro de telefones?

**Resposta:**

O cadastro de telefones está no código do sistema (dicionário hardcoded). Para atualizar:

1. **Colete o número** do advogado (com DDD e código do país)
2. **Entre em contato** com o suporte técnico
3. **Informe:**
   - Nome completo do advogado
   - Número de telefone no formato: 5571999999999
   - Área de atuação (Controle Trabalhista, Cível, etc.)
4. O suporte técnico atualizará o sistema
5. A atualização entra em vigor na próxima sincronização

**⚠️ Importante:** O formato do telefone deve ser: `55` (Brasil) + `71` (DDD) + `999999999` (número)

### ❓ Posso responder às mensagens de alerta?

**Resposta:** 

Tecnicamente sim, mas **não é recomendado**. As mensagens de alerta são apenas notificações para você. 

O correto é:
- **Você** entra em contato com o advogado
- **O advogado** responde à mensagem original que ele recebeu
- Isso garante que o sistema registre corretamente

### ❓ E se eu receber múltiplos alertas do mesmo advogado?

**Resposta:**

Isso **não deveria acontecer** - o sistema tem proteção contra duplicatas. Se acontecer:

1. **Verifique** se são audiências diferentes (IDs diferentes)
2. Se for a mesma audiência:
   - Pode ser um bug do sistema
   - Entre em contato com o suporte técnico
   - Informe o ID da audiência e horário dos alertas

### ❓ O sistema funciona em feriados?

**Resposta:** 

Sim! O sistema funciona **24 horas por dia, 7 dias por semana**, incluindo feriados. 

Se houver audiências agendadas em feriados, você receberá os alertas normalmente.

### ❓ Posso desativar os alertas?

**Resposta:**

Não é recomendado, pois você é o responsável pela pauta. Porém, se houver necessidade (férias, afastamento):

1. **Informe a gestão** com antecedência
2. **Defina um substituto** para receber os alertas
3. **Entre em contato** com o suporte técnico para atualizar o telefone temporariamente
4. Após retorno, solicite a reversão

### ❓ Como sei se o advogado realmente compareceu?

**Resposta:**

O sistema registra apenas a **confirmação do advogado**, não o comparecimento físico. Para verificar:

1. **Check-in confirmado** = Advogado disse que vai comparecer
2. **Check-out confirmado** = Advogado disse que participou
3. Para confirmar comparecimento real:
   - Consulte atas de audiência no DataJuri
   - Verifique relatórios do advogado
   - Consulte registros do tribunal

### ❓ E se o advogado responder depois que eu já entrei em contato?

**Resposta:**

Sem problemas! O importante é garantir que a situação foi resolvida.

1. Se o advogado responder ao sistema depois do seu contato: **ótimo!** ✅
2. O sistema registrará a resposta normalmente
3. Você pode confirmar no banco de dados que o status foi atualizado
